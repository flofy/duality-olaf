# World 3 — Coordination

World 3 is the first campaign where the second form is deliberately treated as a movable obstacle.

| Level | Design intent |
| --- | --- |
| 01 | mutual stopping point |
| 02 | ball as obstacle / false shortcut |
| 03 | responsibility relay |
| 04 | central interaction |
| 05 | multi-step preparation |
| 06 | relay positioning |
| 07 | shared corridor |
| 08 | asymmetric double relay |
| 09 | prepare → switch → return |
| 10 | multi-objective asymmetric route |
| 11 | dense coordination / recovery planning |

All eleven layouts are solver-validated in `World3Coordination.test.ts`. The layouts are intentionally distinct from the earlier World 1/2 patterns.

Human playtesting remains a balancing step after merge; solver validity is the automated gate, not a replacement for feel and difficulty tuning.
